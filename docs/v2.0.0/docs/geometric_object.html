Module voltrace.geometric_object

The geometric object module defines the GeometricObject abstract base class, which provides move, rotate, and mirror operations to any geometry that implements map_points. All mesh and field classes inherit from it.

Classes

class GeometricObject

The Mesh class (and the classes defined in voltrace.geometry) are subclasses of GeometricObject. This means that they all can be moved, rotated, mirrored.
